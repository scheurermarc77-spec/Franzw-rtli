FRANÇAIS KARTEN – iPHONE WEB-APP

Enthalten:
- Deutsch -> Französisch Karteikarten
- Antwort eintippen und prüfen
- Richtige Antwort: grüner Rahmen
- Falsche Antwort: roter Rahmen
- Danach Karte antippen -> Lösung sichtbar
- Karte als "Repetieren" markieren
- Französische Lösung antippen -> Aussprache auf Französisch
- Eigene Gruppen erstellen
- Eigene Karten erstellen/bearbeiten/löschen
- Spracheingabe, sofern der Browser SpeechRecognition unterstützt
- Offline-Wörterbuch für einfache Übersetzungsvorschläge
- Speicherung direkt auf dem Gerät (localStorage)
- Als PWA auf dem iPhone-Homescreen installierbar

WICHTIG:
Eine HTML-Datei direkt aus der Dateien-App reicht für die PWA-Installation nicht.
Lege den Ordner auf einen HTTPS-Webspace (z.B. GitHub Pages, Netlify, eigener Webserver).
Dann in Safari öffnen -> Teilen -> "Zum Home-Bildschirm".

Für hochwertige automatische Übersetzungen kann später eine API (DeepL/OpenAI o.ä.)
angebunden werden. Dafür sollte der API-Schlüssel nicht direkt im Browser gespeichert
werden, sondern über einen kleinen Server/Backend-Endpunkt laufen.
