Neu:
- Treffer/Versuche werden beim Öffnen der App auf 0 zurückgesetzt.
- Treffer/Versuche werden beim Wechsel der Lerngruppe auf 0 zurückgesetzt.
- Jede Gruppe hat einen dauerhaften Abschlusszähler.
- Sobald "Toll gemacht!" erreicht wird, steigt der Zähler der betreffenden Gruppe um 1.
- Bei "Alle Gruppen" werden die Abschlusszähler aller Gruppen mit Karten um 1 erhöht.
- In der Gruppenauswahl und unter "Verwalten" ist sichtbar, wie oft eine Gruppe vollständig geschafft wurde.

Alle bisherigen Funktionen bleiben erhalten.
