FRANÇAIS KARTEN – VERSION 7

Dieses Paket enthält ALLE Dateien, die du für GitHub Pages brauchst.

Auf GitHub hochladen:
- index.html
- manifest.webmanifest
- sw.js
- kompletter Ordner icons/

Am einfachsten: den Inhalt dieses ZIP-Pakets komplett in dein Repository hochladen
und vorhandene Dateien ersetzen.

Danach:
1. GitHub Pages kurz aktualisieren lassen.
2. Seite in Safari neu laden.
3. Prüfen, ob in der App 'Version 7 · Neues iPhone-Icon' steht.
4. Falls bereits eine alte App auf dem Home-Bildschirm liegt, diese entfernen.
5. Safari: Teilen -> Zum Home-Bildschirm -> Hinzufügen.

Das neue Icon wird dann auf dem iPhone-Homescreen verwendet.
